dACE.jl

Directional atomic cluster expansion (dACE) learns rotation-equivariant, body-ordered acceleration rules from collective trajectory data. Each agent's acceleration is expanded in pure (self-interaction-free) basis functions of its own velocity and its neighbours' relative positions and velocities. Contributions from each body order can be read off the fitted model.

The 2D basis is equivariant under joint rotations. In 3D, the model uses the agent's heading frame, or a fixed vertical frame for systems with gravity.

Installation

Requires Julia 1.11 or later. The package is not yet registered; install it directly from GitHub:

using Pkg
Pkg.add(url="https://github.com/TSGut/dACE.jl")

For experiment scripts and tracking-data setup, see Reproducing the paper.

Two dimensions

Build a local environment for each agent from positions and velocities at one time step, then evaluate a dACE basis for one agent:

using dACE

positions = [0.0 1.0 -1.0; 0.0 0.5 0.0]
velocities = [1.0 0.8 0.9; 0.0 0.1 -0.1]
envs = environments(positions, velocities; cutoff = 2.0)

basis = dACEBasis(maxdeg = (2, 3, 3), cutoff = 2.0)
features = evaluate(basis, envs[1])

A workspace belongs to one basis and must not be shared by concurrent tasks. Batch prediction and fitting manage their own reusable workspaces. Environment construction uses NeighbourLists.jl cell lists, retaining one minimum-image displacement per neighbour and the strict distance < cutoff condition in both 2D and 3D.

Three dimensions

In 3D, heading_bases creates separate bases for acceleration perpendicular and axial to the focal agent's heading:

positions = [0.0 1.0 -1.0; 0.0 0.5 0.0; 0.0 0.0 0.5]
velocities = [1.0 0.8 0.9; 0.0 0.1 -0.1; 0.0 0.0 0.1]
envs = environments(positions, velocities; cutoff = 2.0)

perpendicular, axial = heading_bases(maxdeg = (2, 3), cutoff = 2.0)
features = (evaluate(perpendicular, envs[1]), evaluate(axial, envs[1]))

Fit from trajectories

For trajectory arrays with dimensions (dimension, agent, time), derive environments and acceleration targets, then fit the 2D basis:

envs, accs = trajectory_data(positions2d, velocities2d, dt; cutoff = 2.0)
model = fit(basis, envs, accs)
acceleration = predict(model, envs[1])

In 3D, use the pair from heading_bases:

envs, accs = trajectory_data(positions3d, velocities3d, dt; cutoff = 2.0)
model3d = fit((perpendicular, axial), envs, accs)
acceleration3d = predict(model3d, envs[1])

Use vertical_bases instead when the system has a preferred vertical axis, such as motion under gravity.

fit minimises the squared error plus a ridge penalty λ² Σₖ γₖ |c̃ₖ|² on the coefficients of the column-normalised basis (prior = smoothness_prior(basis) for the algebraic smoothness prior of ACE). By default it streams the design through a QR factorisation, one chunk of environments at a time, so memory depends on the basis size only and the condition number is that of the design, not its square. method = :normal_equations accumulates the normal equations instead, which is cheaper per environment but loses accuracy at weak regularisation. fit_path returns the fits for a list of λ from a single pass over the data.

Options for tracking data

Animal trajectories often need more than positions and velocities. All options keep the basis exactly equivariant and are available in 2D and 3D:

  • memory = true (or :onebody, only in the 1-body term): the agent's past acceleration, env.a, enters the centre functions.
  • neighbour_memory = true: each neighbour's past acceleration, env.an, enters its one-particle functions. environments(...; acc) and trajectory_data(...; memory = true) fill in both.
  • speedmap = :tanh: velocities and accelerations are mapped to tanh(|x| / scale) x / |x| before the polynomials, which resolves heavy-tailed speeds (bursts and glides) evenly. The default is the linear x / scale.
  • normaliser = (c, p): interaction terms are divided by (c + S₀)^p, S₀ = Σⱼ fc(ρⱼ), a fixed normalisation by crowding.
using dACE

positions = [0.0 1.0 -1.0; 0.0 0.5 0.0]
velocities = [1.0 0.8 0.9; 0.0 0.1 -0.1]
past_accelerations = [0.3 0.0 -0.1; 0.1 -0.4 0.2]
envs = environments(positions, velocities; cutoff = 2.0, acc = past_accelerations)

basis = dACEBasis(maxdeg = (4, 4), cutoff = 2.0, memory = true, neighbour_memory = true,
    speedmap = :tanh, normaliser = (1.0, 1.0))
features = evaluate(basis, envs[1])
