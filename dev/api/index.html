API reference

dACE.dACE — Module
dACE

Directional atomic cluster expansion: pure body-ordered, rotation-equivariant expansion of an agent's acceleration in its own velocity and its neighbours' relative positions and velocities.

source
dACE.ARModel — Type
ARModel(model, ρ)

aᵢ(t) = F(envᵢ(t)) + ηᵢ(t), ηᵢ(t) = ρ ηᵢ(t - Δ) + ξ: force law F = model and persistent individual noise. predict(m, env): the force law; predict(m, env, penv, pacc): one step ahead given the environment and acceleration a step Δ earlier.

source
dACE.BasisFunction — Type
BasisFunction

B = ψ(vᵢ) Σ_{j₁≠⋯≠j_N} ∏ₜ φ_{kₜ}(r_{jₜ}, u_{jₜ}), N = length(ks), stored as Σ μ ∏ A_block (terms).

source
dACE.Centre — Type
Centre(p, m, q = 0, k = 0)

ψ = Pₚ(2|ṽ|² - 1) ṽ^m |ã|^{2q} ã^k, ṽ, ã: scaled velocity and past acceleration (see scaled); charge m + k.

source
dACE.CompositeBasis — Type
CompositeBasis(interaction, self)

The columns of interaction (a dACEBasis, evaluated on h.env) followed by those of self (a SelfHistoryBasis), for HistoryEnvironments h; fitted and predicted as one linear model (fit, qr_statistics, predict). bodyorder_contributions returns the interaction body orders and, last, the self-history term.

source
dACE.Environment — Type
Environment(v, r, u, a = 0, an = [])

v = vᵢ; r[j] = xⱼ - xᵢ, u[j] = vⱼ - vᵢ for neighbours within the cutoff (2D); a: past acceleration of agent i (used by bases with memory = true); an[j]: past acceleration of neighbour j (used by bases with neighbour_memory = true; empty: zero). A neighbour at r[j] = 0 has no direction and is an error (coincident positions, e.g. merged tracking identities, have to be removed beforehand).

source
dACE.Environment3 — Type
Environment3(v, r, u, a = 0, an = [])

v = vᵢ; r[j] = xⱼ - xᵢ, u[j] = vⱼ - vᵢ for neighbours within the cutoff (3D); a: past acceleration of agent i (used by bases with memory = true); an[j]: past acceleration of neighbour j (used by bases with neighbour_memory = true; empty: zero). A neighbour at r[j] = 0 is an error, as in 2D.

source
dACE.HeadingARModel — Type
HeadingARModel(model, θ, vscale)

aᵢ(t) = F(envᵢ(t)) + ηᵢ(t) with heading-frame AR(1) noise ηᵢ(t) = ρ₁(s) ηᵢ(t - Δ) + ρ₂(s) ê² conj(ηᵢ(t - Δ)) + ξ (complex notation, ê, s: heading and speed of agent i at t), ρⱼ(s) = Σₘ θ[j, m] Pₘ₋₁(2 tanh(s / vscale) - 1). Along the heading the noise has coefficient ρ∥ = ρ₁ + ρ₂, across it ρ⊥ = ρ₁ - ρ₂ (see noise_coefficients). predict(m, env): the force law; predict(m, env, penv, pacc): one step ahead given the environment and acceleration a step earlier. From fit(...; noise = :ar1_heading).

source
dACE.HeadingARStatistics — Type
HeadingARStatistics

Streamed QR factor R of the augmented design of the heading-frame AR(1) model (see the top of headingnoise.jl) for a design of K columns and M speed functions, accumulated over n samples; anisotropic = false: without the ê² conj(ηₚ) term (speed-dependent isotropic AR(1), ρ₂ = 0). Pooled with +; used by ar_solve and ar_sse.

source
dACE.HeadingBasis — Type
HeadingBasis(; maxdeg = (4, 8, 6), charge = 1, cutoff = 5.0, rscale = cutoff / 2,
             vscale = 2.0, maxm = 1, maxl = 0, maxa = 2, maxb = 1, vertical = false,
             memory = false, ascale = 1.0, maxk = 1, maxj = 1, speedmap = :linear,
             neighbour_memory = false, maxkn = 1, maxjn = 1, normaliser = nothing)

Basis of total charge charge (1: a₁ + i a₂; 0: a₃) in the frame e₃ = v̂ᵢ, with centres Pₚ(2|ṽ| - 1). vertical = true: fixed frame e₃ = ẑ (symmetry: rotations about the vertical only, e.g. under gravity), centres Pₚ(2|ṽ⊥|² - 1) P_q(ṽ₃) ṽ⊥^m of charge m. memory = true: centres times ã⊥^k ã₃^j (past acceleration in the frame, charge k), |k| ≤ maxk, j ≤ maxj; memory = :onebody: only in the 1-body term. neighbour_memory = true: one-particle functions times b̃⊥^k b̃₃^j (the neighbour's past acceleration), |k| ≤ maxkn, j ≤ maxjn. speedmap, normaliser: as for dACEBasis.

source
dACE.HeadingModel — Type
HeadingModel(perp, c_perp, axial, c_axial)

aᵢ = Re(a⊥) e₁ + Im(a⊥) e₂ + a∥ e₃, a⊥ = Σ c_perp B_perp, a∥ = Re Σ c_axial B_axial.

dACE.OneParticle — Type
OneParticle(n, l, mr, mu, q = 0, k = 0)

φ = fc(ρ) Pₙ(y(ρ)) Pₗ(2|ũ|² - 1) r̂^{mr} ũ^{mu} |b̃|^{2q} b̃^k, ũ, b̃: scaled relative velocity and past acceleration of the neighbour (see scaled), z^{-m} := z̄^m; charge mr + mu + k.

dACE.OneParticle3 — Type
OneParticle3(n, a, mr, l, b, mu, k = 0, j = 0)

φ = fc Pₙ(y) P_a(t) w^{mr} P_l(2|ũ⊥|² - 1) P_b(ũ₃) ũ⊥^{mu} b̃⊥^k b̃₃^j, r̂ = (w, t), ũ = (ũ⊥, ũ₃) and b̃ = (b̃⊥, b̃₃) (scaled relative velocity and past acceleration of the neighbour) in the frame; charge mr + mu + k.

Purification3

dACE.QRStatistics — Type
QRStatistics

Upper-triangular factor R of the augmented design, columns [B t] (K + 1) or, for the AR(1) noise model, [B Bₚ t tₚ] (2K + 2) with the lagged design and targets, accumulated over n rows (qr_statistics, or add_rows! for a design built elsewhere). Statistics of separate data sets pool with +; select_columns keeps a subset of the design columns.

dACE.SelfHistoryBasis — Type
SelfHistoryBasis(; lags = 4, maxdeg = (8, 4), maxm = 2, vscale = 2.0)

Equivariant functions of the agent's current speed s₀ and its past velocities wₖ = vᵢ(t - kΔ), k = 1:lags, in the frame of the current heading ê: B = ê P_n(x₀) ∏ₜ P_qₜ(xₖₜ) ζₖₜ^mₜ, xₖ = 2 tanh(|wₖ| / vscale) - 1, ζₖ = ê* wₖ / |wₖ|, |m| ≤ maxm, temporal order 1 (one past time, total degree ≤ maxdeg[1]) and 2 (two different past times, ≤ maxdeg[2]). Functions of the current speed alone are left to the interaction basis (its 1-body term). Real coefficients (reflections = true) make the expansion reflection-equivariant. Used inside a CompositeBasis on HistoryEnvironments.

dACE.dACEBasis — Method
dACEBasis(; maxdeg = (2, 8, 6), cutoff = 5.0, rscale = cutoff / 2, vscale = 2.0,
          maxl = 2, maxm = 2, inner = 0, filter = (ψ, φs) -> true, pure = true,
          memory = false, ascale = 1.0, maxk = 1, maxq = 0, speedmap = :linear,
          neighbour_memory = false, maxkn = 1, maxqn = 0, charge = 1, normaliser = nothing)

Basis of total charge charge (1: the acceleration aₓ + i a_y; 0: invariants); maxdeg[N + 1]: total degree at correlation order N; rscale: length scale of the radial map y(ρ) (small values resolve short distances finely); maxl, maxm bound l, |mr|, |mu|. inner = q: envelope fc(ρ) ((1 - y(ρ))/2)^q, vanishing at ρ = 0. pure = false: self-interacting products ψ ∏ₜ Σⱼ φ_{kₜ}(xⱼ) on the same index set. memory = true: centres also depend on the past acceleration, |k| ≤ maxk, q ≤ maxq; memory = :onebody: only in the 1-body term (persistence of the agent's own motion, memoryless neighbour terms). neighbour_memory = true: one-particle functions also depend on the neighbour's past acceleration, |k| ≤ maxkn, q ≤ maxqn. speedmap: map from velocities and accelerations to the scaled ṽ, ũ, ã, b̃ (scales vscale, ascale); :tanh keeps all magnitudes below 1, where the speed polynomials are resolved evenly (see scaled). normaliser = (c, p): every function of correlation order N ≥ 1 is divided by (c + S₀)^p, S₀ = Σⱼ fc(ρⱼ) (fixed crowding normalisation; p = 1: averaging over neighbours, p = 1/2: Finnis–Sinclair-like).

source
dACE.fit — Method
fit(basis, envs, accs; λ = 1e-6, prior = nothing, chunksize = 2000, reflections = false, method = :qr)
fit(basis, envs, accs; noise = :ar1, past = (penvs, paccs), kwargs...) -> ARModel
fit(basis, envs, accs; noise = :ar1_heading, past = (penvs, paccs), noise_degree = 2, kwargs...) -> HeadingARModel
fit(basis, envs, accs; solver)

min Σₛ |aₛ - Σₖ cₖ Bₖ(envₛ)|² + λ² Σₖ γₖ |c̃ₖ|² (c̃: column-normalised basis, γ = prior, default 1; see smoothness_prior). method = :qr (default): streamed QR of the design, one chunk of environments at a time (qr_statistics), so that memory does not grow with the data and the condition number is that of the design; method = :normal_equations: the normal equations accumulated over chunks, which square the condition number but are cheaper to accumulate. With an ACEfit solver, a direct solve of the full design matrix. reflections = true: c ∈ ℝᴷ, i.e. reflection equivariance. noise = :ar1: persistent individual noise η(t) = ρ η(t - Δ) + ξ, fitted jointly with the force law by Cochrane–Orcutt iteration (past: environments and accelerations a step Δ earlier, as from trajectory_data(...; past = true)). noise = :ar1_heading: the same with separate coefficients along and across the heading that depend on the speed (degree noise_degree, see HeadingARModel), by streamed QR only.

dACE.heading_ar_statistics — Method
heading_ar_statistics(rows!, n, K; degree = 2, vscale, anisotropic = true, chunksize = 2000, workspace = () -> nothing)

dACE.trajectory_data — Method
trajectory_data(pos, vel, dt; cutoff, extent, periodic, steps, memory = false, past = false)
    -> (envs, accs) or, with `past`, (envs, accs, penvs, paccs)
